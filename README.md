# file-toss

Fast and secure file transfer from your terminal to your mobile device via QR code.

## Features

- Transfer files over your local Wi-Fi network instantly.
- Zero configuration required on the receiving device. Just scan the QR code and download.

## Usage

You can run the package directly without installing it by using `npx`:

```bash
npx ftoss <path-to-file>


Alternatively, you can install it globally on your system:
npm install -g file-toss
ftoss <path-to-file>
